# 📌 Project Overview

This project focuses on the analysis and visualization of educational institutions in Morocco using **Power BI**.  
The dataset was collected from Morocco’s official open data platform and transformed into an interactive dashboard to provide insights about the distribution of schools across regions and provinces.

---

# 🌍 Data Source

📂 Official Open Data Portal:

https://data.gov.ma/data/fr/group/education

---

# 🎯 Objectives

✔ Analyze the distribution of educational institutions in Morocco  
✔ Explore regional and provincial disparities  
✔ Build an interactive and dynamic dashboard  
✔ Facilitate data-driven decision making  
✔ Improve data visualization and reporting skills  

---

# 🧹 Data Preparation

The data preparation phase was performed using **Power Query** inside Power BI.

## 🔧 Cleaning Process

### ✅ Handling Missing Values
- Replaced missing values with `null`

### ✅ Column Optimization
Removed unnecessary columns such as:
- Commune

Kept important columns including:
- Institution Name
- Region
- Province
- Educational indicators

### ✅ Data Standardization
- Corrected inconsistent values
- Cleaned text formatting
- Improved data quality for visualization
